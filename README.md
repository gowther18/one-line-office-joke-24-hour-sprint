One joke about office life, 98 characters, one line: the fire drill is the only meeting everyone attends on time — because it is the only one with an exit plan. The setup is a truth anyone who has sat in an office recognises (the fire drill is the best-attended meeting in the building); the payoff turns on "exit plan", which means the fire escape and, at the same time, the way out of the job. This program writes that one line to /output/entry.txt; a judge model compares the jokes two at a time, and the funniest lines take the pool.

## Run it

```sh
python3 main.py
```

Writes /output/entry.txt. Outside the grader's sandbox, `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.txt` instead.
